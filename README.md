# ЗАЦЕПКА (Zatsepka)

Локальное приложение для сбора лидов с карт Google, Яндекс и 2ГИС, дедупликации, обогащения и подготовки сообщений. Работает только на вашем компьютере: сервер слушает `127.0.0.1:8000`, облачные API, ключи карт, аккаунты и подписки не используются.

## Что умеет

- Поиск по списку городов и категорий сразу в трёх источниках, с пропуском уже искавших пар за N дней.
- Сбор карточек: названия, адреса, телефоны, сайты, соцсети, рейтинги, отзывы, часы работы (зависит от того, что отдаёт источник).
- Дедупликация по телефону или по названию + расстоянию, объединение данных из разных источников.
- Обогащение сайтов: почты, телефоны, соцсети, определение конструктора сайта (Tilda, Wix и др.) и флагов «Без сайта», «Только соцсети», «Шаблон».
- Вкладки «Парсер» / «База» / «Сообщения», поиск, фильтры, экспорт в CSV (с BOM) и XLSX.
- Конструктор промптов для чатбота: промпт собирается локально, модель не вызывается; вы копируете промпт, вставляете ответ в поле сообщения и сами нажимаете Send в мессенджере.
- Генерация ссылок: WhatsApp (`wa.me`), Telegram (`t.me` / `tg://resolve`), Instagram, Viber, Email (`mailto:`), звонок (`tel:`). Статусы «Отправлено» / «Ответили».
- Дашборд модулей, живые логи, очередь, supervisor, метрики CPU/RAM/disk, статус Ollama (только индикатор), страница «Диагностика».

## Быстрый старт

1. Установите Python 3.12 и Google Chrome.
2. Запустите `run.bat` двойным кликом. Он создаст `.venv`, установит зависимости из `requirements.txt`, выполнит `playwright install chromium` и поднимет сервер.
3. Откроется вкладка `http://127.0.0.1:8000`. Если браузер не открылся — откройте адрес вручную.
4. Если порт 8000 занят, `run.py` напишет об этом и выйдет — освободите порт или закройте другую копию приложения.

Важно: если вы запускали приложение из временной копии или до переименования, старый сервер может остаться на порту 8000 и показывать прежний интерфейс. Закройте все старые окна/процессы `run.py` и перезапустите `run.bat` из этой папки.

## Как пользоваться

### Поиск

1. На странице «Поиск» слева добавьте города и категории (кнопки `+`, «добавить все»). Уберите лишние крестиком.
2. В блоке «Параметры» включите/выключите «Не повторять пары…», настройте число дней пропуска, паузы и лимиты. Внизу сразу видна оценка: сколько пар будет пропущено и сколько осталось.
3. Включите источники (Google / Яндекс / 2ГИС) и нажмите «Начать поиск».
4. Если появится капча или экран согласия — окно браузера останется видимым; решите его вручную. Бэкенд ждёт до 10 минут, затем статус становится `needs_human`/paused. Продолжить можно кнопкой «Пауза»→ ещё раз.
5. Карточки лидов появляются справа по мере сбора (SSE). Кнопки «Пауза» и «Стоп» управляют запуском. Состояние задания хранится в БД и восстанавливается после перезапуска.
6. Вкладки сверху: «Парсер» (новые лиды последнего задания), «База» (все остальные статусы), «Сообщения» (лиды с историей сообщений).

### Карточка лида

- Флаги: «Без сайта», «Только соцсети», «Шаблон», «Ждёт ответа», «N компаний».
- Кнопки соцсетей ведут на профиль/мессенджер; серая кнопка означает отсутствие контакта.
- «+ В базу» меняет статус на `in_base`.
- Клик по карточке открывает панель справа: контакты, карта (Leaflet + OSM, офлайн — точечная сетка), источники, заметки (автосохранение), блок сообщения, навигация ‹ ›, закрытие по `Esc`.

### Сообщения (без автоотправки)

1. Откройте лид → «Собрать промпт» → «Скопировать промпт».
2. Вставьте промпт в чатбот (ChatGPT, локальный ИИ и т.п.), скопируйте ответ.
3. Вставьте ответ в поле «Текст сообщения» в карточке. Для email заполните «Тема письма».
4. Нажмите кнопку канала — откроется сайт мессенджера с подставленным номером/UserName; для Telegram и Instagram текст копируется в буфер.
5. Отправку выполняете **вы сами**. Затем нажмите «Отметить отправленным» (статус `waiting_reply`) или «Ответили» (статус `replied`).

### Прочее

- «Настройки» —country/город/регион телефонов, домен 2ГИС, паузы, лимиты, `skip_days`, URL Ollama, `my_offer`, тон и длина промпта, горячие клавиши. Изменения применяются без перезапуска.
- «Отбор» — сохранённые пресеты фильтров; «Графики» — лиды по дням/источникам/флагам, воронка; «Профиль» — локальное имя, аватар и статистика; «Клавиши» — список хоткеев; «Помощь» — краткая инструкция.
- «Дашборд» (первый пункт меню) — карточки модулей, Start/Stop/«В очередь», системные метрики, живой лог, Ollama. Модули hh/habr/freelance помечены «скоро».

Горячие клавиши (не срабатывают при вводе в поля): `/` — поиск, `J`/`K` — следующая/предыдущая карточка, `B` — в базу, `Enter` — открыть карточку, `Esc` — закрыть, `S` — начать поиск.

## Данные и файлы

- `data/zatsepka.db` — SQLite в режиме WAL; копии на старте сохраняются в `data/backups/` (последние 5).
- `data/browser_profile/` — постоянный профиль Chrome. Одновременно можно работать только с одним профилем.
- `debug/capture/<источник>/<время>/` — HTML, скриншоты и перехваченные JSON-ответы; `debug/ui/` — скриншоты страниц.
- `logs/app.log` и `logs/<module>.log` — вращающиеся логи.
- Всё перечисленное в `.gitignore` и не попадает в репозиторий.

## Тесты

```
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe -m pytest -q --cov=app --cov-report=term
.venv\Scripts\python.exe -m pytest -m live -q
```

Обычные тесты работают офлайн и занимают ~20 с. `live` обращается к реальным сайтам (только Россия / Саратов), ничего не отправляет и по умолчанию пропускается. Текущие результаты и известные ограничения — в `FINAL_REPORT.md`.

## Командная строка

```
python -m app.tools.capture google 'барбершоп' --city 'Саратов' --auto
python -m app.tools.scrape google 'барбершоп' --city 'Саратов' --max 20
python -m app.tools.run_job --country 'Россия' --cities 'Саратов,Энгельс' --categories 'барбершоп' --sources google,yandex,twogis --max 60
python -m app.tools.peek debug/capture/google/<время>/responses/resp_0000.json --depth 3
```

`capture` сохраняет фикстуры в `debug/capture/`, `peek` просматривает Large JSON/HTML порциями, `scrape` печатает таблицу и покрытие полей, `run_job` запускает полный цикл с дедупликацией.

## Устройство

`app/browser` — синхронный Playwright в отдельном потоке и перехват ответов; `app/scrapers` — чистые функции парсинга + тонкий слой браузера; `app/core` — нормализация, дедупликация, события и воркер заданий; `app/enrich` — сайты и соцсети; `app/ai` — промпты и статус Ollama; `app/web` — шаблоны, API и статические файлы (HTMX/Alpine/Chart.js/Leaflet вендорированы); `app/hub` — реестр модулей, очередь, supervisor и метрики.

## Ограничения

Подробный список с доказательствами — в `FINAL_REPORT.md` (раздел KNOWN ISSUES). Кратко: live-слой карт собирает в основном название и адрес; 2ГИС по запросу «барбершоп» в Саратове отдаёт 12 фирм; при отсутствии телефона/соцсети Telegram-ссылка ведёт на `https://t.me/`.
